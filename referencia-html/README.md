# Referência — páginas originais da Parte 1

Cópia das páginas HTML do site do grupo (Parte 1), mantidas sem alterações
para permitir a comparação antes/depois da migração para React.

| Arquivo | O que é | Onde foi parar no React |
|---|---|---|
| `index.html` | Página inicial do grupo | Seções Hero, Destaques, Categorias e Newsletter da Landing Page (`/`) |
| `entretenimento.html` | Minha página | Seção Entretenimento da Landing Page (`/#entretenimento`) |
| `sobre.html` | Página Sobre Nós | Rota `/sobre` |
| `entrenoticia1.html` a `entrenoticia5.html` | Matérias completas ligadas à minha página | Não migradas (ficam só como referência) |
| `css/style.css` | Estilos do site | `src/index.css` (com variáveis de cor) |
| `js/script.js` | Data, carrossel e newsletter | Hooks `useState`/`useEffect` nos componentes |

As imagens não foram copiadas para esta pasta (algumas tinham mais de 20 MB).
As versões otimizadas estão em `public/img/`.
